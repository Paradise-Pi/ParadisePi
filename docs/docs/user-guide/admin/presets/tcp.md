title: TCP
---

TCP presets are for sending Hex Code Messages over TCP. They are often used to send commands to specialist AV hardware that receives Modbus over TCP, such as [Waveshare Relay Boards](https://www.waveshare.com/wiki/Modbus_POE_ETH_Relay#Single_Relay_Control).

HTTP presets _must_ be linked to a device, which stores the IP address and of the device in one place.
